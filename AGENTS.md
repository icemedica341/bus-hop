# AGENTS.md: AI Agent Guide for Bus-Hop

This file tells AI coding agents how to work with this repository. Read this first before editing any code.

## Overview

BusHop is a lightweight Android bus arrival viewer for Singapore and Taipei, built with Kotlin and Jetpack Compose. It provides real-time bus arrivals, smart search across 5,201 stops, drag-to-reorder, pinning, and Material 3 theming.

**Status**: Archived per [ADR-004](docs/adr/ADR-004-archival.md). No active development — security-only maintenance (≤2h/week). CI/CD intentionally removed; local quality gates only.

## Key Facts

- **Language**: Kotlin 2.4.0
- **UI**: Jetpack Compose (BOM 2026.05.01) + Material 3
- **Architecture**: MVVM + Clean Architecture (3 modules: app/data/domain)
- **DI**: Manual constructor injection through ViewModel Factory
- **Networking**: Retrofit 3 + OkHttp 5
- **Persistence**: DataStore Preferences
- **Search**: Inverted index + TokenTrie (prefix) + Levenshtein (fuzzy)
- **Testing**: JUnit 4, MockK, Coroutines Test — 161 tests across 9 test classes
- **Gradle**: 9.4.1, AGP 9.1.0, minSdk 26, targetSdk 37
- **API**: Arrivelah (arrivelah2.busrouter.sg), no API key required
- **License**: MIT
